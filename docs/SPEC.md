# Curve Analysis - 飞控日志数据绘图工具

## 项目概述

C# WinForms GUI 工具，用于加载飞控日志 CSV 文件，将数据绘制为曲线图进行多文件对比分析。

## 技术栈

- C# / .NET 10 (WinForms)
- [OxyPlot](https://github.com/oxyplot/oxyplot) 2.2.0（图表核心 + WinForms 集成）
- 自包含单文件 EXE（~50MB），无需安装 Python/.NET 运行时

## 数据格式

CSV 文件，每行一个采样时刻，典型文件包含 400+ 列数据字段。
第一行是表头（字段名），数据从第二行开始。
支持 GBK 和 UTF-8 编码自动检测。

## 两个版本

### V13 叠图版（基础）
多个 CSV 文件的数据叠加显示在同一张图上，用不同颜色区分数据来源。

### V16 合并版（推荐）
V13 全部功能 + 多图表管理 + 高级分析功能（基线对比、网格布局、浮动窗口等）。

## 核心功能需求

### 1. 文件加载
- 支持同时加载多个 CSV 文件
- **懒加载**：只先读取表头（第一行），用户选中字段后才加载对应列的数据
- 兼容 GBK 和 UTF-8 编码
- 支持文件拖拽加载（从资源管理器拖入）

### 2. 数据字段列表
- 左侧面板显示所有字段名（从表头读取）
- 按文件分组显示
- 可搜索/过滤字段（模糊匹配）
- 支持双击字段名添加曲线
- 支持拖拽字段到图表区域绘制曲线

### 3. 图表功能
- 折线图，曲线加粗（StrokeThickness 2.5）
- 高对比度 12 色 RGB 配色方案
- 滚轮缩放、右键平移
- 双击删除曲线
- 单击显示数据（点击图表显示所有曲线在该位置的 Y 值）
- 图表保存为 PNG 图片

### 4. 多图表管理（V16）
- 新建/删除/清除独立图表
- 一键合并所有曲线到同一图表（全部叠到一图）
- 按文件自动分图（仅显示已加载的字段）
- 图表标题栏显示当前曲线数量

### 5. 布局控制（V16）
- 自适应布局：根据图表数量自动计算最佳行列布局
- 手动布局：输入行数和列数，点击应用
- 浮动窗口：图表弹出到独立窗口

### 6. 基线对比（V16）
- 红色竖线贯穿所有图表
- 交叉点显示数据标签
- 标签防重叠（Y 值接近时自动错开）

### 7. 背景色和配色（V16）
- 四种背景主题：白色/浅灰/黑色/深灰
- 高对比度 12 色 RGB 配色方案

### 8. 预设收藏（V16）
- 保存当前曲线组合为预设
- 双击预设一键应用
- 预设持久化到本地文件

### 9. 性能优化
- **懒加载列数据**：首次访问时从磁盘读取，后续从缓存返回
- **自动降采样**：数据点超过 8000 个时按步长抽样，保持渲染性能
- **编码检测**：读取前 8KB，通过字符范围判断 GBK/UTF-8

## 编译和发布

```bash
# 需要 .NET 10 SDK
cd CurveAnalysis_CSharp

# V16（当前版本）
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:EnableCompressionInSingleFile=true \
  -o bin/publish

# V13（叠图版）
cp ../backups/Program_V13_Final.cs Program.cs
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:EnableCompressionInSingleFile=true \
  -o bin/publish_v13
```

## 数据格式要求

- CSV 文件，GBK 或 UTF-8 编码
- 第一行（或指定行）为表头（字段名）
- 字段名支持中文、英文、数字、下划线
- 典型字段：序号、俯仰角、横滚角、航向角、时戳等
- `时戳`字段默认作为 X 轴
