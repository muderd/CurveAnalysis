# Curve Analysis - 飞控日志数据绘图工具

## 项目概述
Python GUI工具，用于加载飞控日志CSV/XLSX文件，将数据绘制为曲线图进行多文件对比分析。

## 技术栈
- Python 3.13
- PyQt5 (GUI框架)
- matplotlib (绑图，嵌入PyQt5)
- pandas (数据加载)
- numpy (数值计算)

## 数据格式
CSV/XLSX文件，每行一个采样时刻，共410列数据字段。
第一行是表头（字段名），数据从第二行开始。
字段定义参考文件：`F:\00_work\18_UFCP_R\02_Tools\文件下载\飞参解析表头(控制律新增20260421).csv`
（格式：数据名称,单个数据字节数,数据类型,比例系数 — 仅用于参考字段含义，程序不需要读取此文件）

## 两个版本

### 版本1：叠加模式 (curve_overlay.py)
多个CSV文件的数据叠加显示在同一张图上，用不同颜色区分数据来源。

### 版本2：分屏模式 (curve_split.py)  
左右两个独立图表视图，每个视图可独立选择CSV文件和数据字段。
用下拉框选择CSV文件，支持同时对比同一CSV中的两个不同字段。

## 核心功能需求

### 1. 文件加载
- 支持同时加载多个CSV或XLSX文件
- **性能优化**：只先加载表头（第一行），不加载全部数据
- 用户选中字段后才加载对应列的数据
- 兼容GBK和UTF-8编码
- 加载速度快，不卡顿

### 2. 数据字段列表
- 左侧面板显示所有字段名（从表头读取）
- 可搜索/过滤字段
- **拖拽交互**：用户把字段从列表拖到图表区域，自动绘制该字段的数据曲线
- 支持双击字段名也添加到图表
- 字段列表支持分类折叠（按前缀分组，如"光纤惯导"、"MZD22"、"2cl"等）

### 3. 图表功能
- **直线图**（折线图，marker点可选）
- 鼠标悬停显示数据值（x, y值和字段名）
- 框选放大：鼠标左键拖拽选区，自动放大该区域（调整X/Y轴范围）
- 右键菜单可恢复全图视图
- X轴默认为数据序号（行号），可切换为其他字段
- Y轴自动比例
- 网格线可开关
- 多条曲线用不同颜色区分，带图例

### 4. 轴范围控制
- 底部面板有X轴范围输入框（最小值、最大值）
- Y轴范围输入框（最小值、最大值）
- "应用范围"按钮：根据输入值调整图表范围
- "自动范围"按钮：恢复自动缩放
- 勾选框：启用/禁用自动范围

### 5. 背景色
- 工具栏有背景色选择器，可调整图表背景色
- 提供几个预设颜色按钮（白色、浅灰、浅蓝、黑色）
- 自定义颜色选择对话框

### 6. 文件标识（版本1叠加模式）
- 每个加载的文件在左侧列表中显示文件名
- 每个文件分配不同颜色
- 图例中标注"文件名 - 字段名"
- 已加载文件列表，可勾选显示/隐藏

### 7. 分屏模式特殊功能（版本2）
- 左右两个独立的matplotlib图表
- 每个图表有独立的文件选择下拉框
- 每个图表有独立的字段选择
- 可以左边选文件A的字段1，右边选文件A的字段2（同一文件不同字段对比）
- 也可以左边文件A，右边文件B（不同文件同一字段对比）
- 同步缩放选项（可选）

### 8. 性能优化
- 使用pandas的chunked reading或usecols只读需要的列
- 大数据量时自动降采样（渲染用，不影响原始数据）
- 使用blitting加速matplotlib重绘
- 字段列表用懒加载
