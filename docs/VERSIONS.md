# CurveAnalysis 版本说明

## 版本架构

| 版本 | 功能范围 | 说明 |
|------|----------|------|
| V13 | 基础叠图 | 纯叠图功能：加载CSV、字段列表、双击绘图、滚轮缩放、右键平移 |
| V14 | 多图管理 | 在V13基础上增加：多图表管理、新建/删除图表、按文件分图 |
| V16 | 合并版 | V13 + V14 全部功能，另加：全部叠到一图、布局、基线对比、高对比度等 |

## V13 叠图版（不应有的功能）

以下功能 **V13 不应包含**，属于 V14/V16：
- 按文件分图
- 按行列显示 / 网格布局
- 全部叠到一图
- 基线对比
- 高对比度配色切换
- 浮动窗口
- 预设收藏

V13 仅有：
- 添加文件
- 清除图表
- 重置视图
- 字段搜索/双击绘图/拖拽绘图
- X轴选择
- 背景色切换
- 网格线开关

## V14 多图版

在 V13 基础上增加：
- 新建图表 / 删除当前图
- 清除当前图 / 清除所有图
- 按文件分图（仅显示已选字段，未选字段的文件不创建图表）

## V16 合并版

V13 + V14 全部功能，另加：
- 全部叠到一图（MergeAllToOverlay）
- 按行列显示 / 网格布局（Grid M×N）
- 基线对比（红色竖线 + 数据标签）
- 高对比度配色
- 浮动窗口
- 预设收藏
- 搜索框模糊过滤
- 保存图片
- 文件拖拽
- X轴粒度控制
- 单击显示数据
- 标签防重叠

## 已知问题

### 2026-05-06: 按文件分图 Bug
**问题**：点击"按文件分图"时，所有文件的所有字段都绘入图表
**修复**：分图前收集已绘制字段，按文件分组；未选字段的文件不创建图表
**影响版本**：V14, V16
