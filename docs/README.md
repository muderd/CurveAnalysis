# Curve Analysis Tool - 飞控日志数据曲线分析工具

Python GUI工具，用于加载飞控日志CSV/XLSX文件，将数据绘制为曲线图进行多文件对比分析。

## 两个版本

### 版本1：叠加模式 (`curve_overlay.py`)
多个CSV文件的数据叠加显示在同一张图上，用不同颜色区分数据来源。

**使用方法：**
1. 运行 `python curve_overlay.py`
2. 点击"打开文件"加载CSV/XLSX文件（支持GBK和UTF-8编码）
3. 左侧字段列表显示所有数据字段（按前缀自动分组，可折叠/展开）
4. **双击字段名** 或 **拖拽字段到图表区域** 即可绘制曲线
5. 左键拖拽框选区域可放大，右键菜单可重置视图

### 版本2：分屏模式 (`curve_split.py`)
左右两个独立图表视图，每个视图可独立选择CSV文件和数据字段。

**使用方法：**
1. 运行 `python curve_split.py`
2. 点击"打开文件"加载数据
3. 左右视图各有独立的文件选择下拉框和X轴字段选择
4. 在右侧字段列表选择目标视图（左/右），然后双击或拖拽字段绘图
5. 勾选"同步缩放"可联动左右视图的缩放

## 功能特性

- **X轴默认时戳**：自动识别"时戳"列作为X轴，可切换为其他字段
- **懒加载**：只先读取表头，选中字段后才加载数据列
- **拖拽绘图**：从字段列表拖拽到图表区域自动绘制
- **搜索过滤**：输入关键字快速定位字段
- **分组折叠**：字段按前缀自动分组，支持折叠/展开
- **悬停提示**：鼠标悬停显示X,Y值和字段名
- **框选放大**：左键拖拽选区自动放大该区域
- **轴范围控制**：手动输入X/Y轴范围，支持自动缩放
- **背景色选择**：预设颜色（白/灰/蓝/黑）+ 自定义颜色
- **网格线开关**：可随时切换网格线显示
- **性能优化**：大数据自动降采样（>8000点），只读取需要的列
- **右键菜单**：画布右键可快速重置视图/切换自动范围

## 依赖安装

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install PyQt5 matplotlib pandas numpy openpyxl
```

## 运行

```bash
# 叠加模式
python curve_overlay.py

# 分屏模式
python curve_split.py
```

## 系统要求

- Python 3.8+
- Windows 10/11（需要显示界面的环境）

## 数据格式

支持CSV和XLSX格式：
- 第一行为表头（字段名）
- 数据从第二行开始
- 支持GBK和UTF-8编码
- X轴默认使用"时戳"列（如有的话），否则用行号
- 文件可包含400+列数据字段

## 源码修改指南

代码结构清晰，便于自行修改：

1. **修改预设颜色**：搜索 `PRESET_COLORS` 字典
2. **修改降采样阈值**：搜索 `DOWNSAMPLE_THRESHOLD` 常量
3. **修改默认X轴字段**：搜索 `DEFAULT_X_FIELD` 常量
4. **添加新功能**：在对应的 `_setup_ui()` 或 `_setup_toolbar()` 方法中添加控件
